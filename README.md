# Mini projetos HTML/CSS/JS (iniciante)

Estrutura:
- Cada projeto está em uma pasta: `proj-01` ... `proj-06`
- Cada pasta contém um `index.html` (e arquivos `css/` e `js/` quando necessário)

## Como rodar
1. Abra o arquivo `index.html` de cada projeto no navegador (duplo clique).
2. Se algum projeto usar arquivos locais JS/CSS, eles já estarão referenciados corretamente.

## Observação
- Sem backend: tudo roda 100% no navegador.
- Se você preferir, também dá para abrir via “Live Server” no VSCode.
